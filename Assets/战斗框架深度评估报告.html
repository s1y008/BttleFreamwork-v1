4架构分层详解

按「数据 → 控制 → 技能/Buff → 表现」逐层评估。

数据层 5 分

BaseUnit → CombatUnit → Warrior / AttackNpc 继承链合理，属性与事件内聚。但 m_Rage 误设 static 导致全局共享；Warrior 的伤害/防御等 getter 无空判（与 Name/Imag 不一致）；死亡链「只 -= 从不 +=」断裂。

控制层 6 分

MoveBase → CombatUnit → Warror/AttackNpc 模板方法模式清晰，AutoFightUpdate 作为扩展点，上轮桥接方法让 FSM 与子类解耦。但 PlayerNeedMove getter 内做物理查询（副作用），索敌每帧 OverlapSphere。

FSM 状态机 8 分

ICombatState + CombatStateMachine 结构干净，转换表合法、受控态结束自动回 Idle。Phase C 起 Stun/Silence 不再各自倒计时，改为每帧查询 Buff 标志位（控制效果唯一真相源在 Buff），转换表补齐 Stun↔Silence / Knockback→Stun/Silence。但 Idle/Move/Attack 状态行为仍落在空桩上（DoAutoFight 无实义）。

Buff 系统 9 分

框架内质量最高的模块：ulong 位枚举 + O(1) 查询、对象池零 GC、免疫/驱散/叠加/刷新语义完整、延后移除队列防事件重入、配置同源校验。现已完整接入战斗主循环：Update() 统一驱动 Tick，OnBuffTickDamage 落地 DoT 伤害（含施加者反查表 + 施加者销毁降级），控制 Buff 事件驱动 FSM 切入 Stun/Silence。

编号位置问题影响

🟠 P1 — 功能断裂 / 高风险

较上次评估减少 3 项：Buff↔FSM 未映射 与 OnAddBuff 空桩 已由 Phase C 修复，死亡链断裂 已降级为 P2（主链路已通，仅事件订阅仍缺）。

编号位置问题影响
P1-1Skill.cs20+ 技能效果（ImmedDamage/Rigor/HitBack/HitOut/OnDizz/OnAirHit/OnUnitMove…）均为空桩，仅 ImmedHeal/AddBuff/Sneer 有实现。技能表现与受击反馈大面积缺失
P1-2Skill.cs:247SetCD 里 TimerManager 被注释，CoolDown=true 后无重置。技能进入冷却后永不恢复
P1-3Warrior.cs:40Damage/Defend/Crit/Parry/Penetrate/MaxHP getter 直接解引用 WarriorBaseData 无空判（与 Name/Imag 不一致）。配置缺失时 NullReferenceException
P1-4BufferData.csvBuffMsg 用 Split('\r')，依赖 CRLF 行尾，工具改 LF 会静默加载 0 行。配置加载脆弱（已在 CODELY.md 记录）
P1-5CommonHelper.Str2Int正则 ^[0-9]+$ 拒绝负数，Str2Int("-1") 返回 0；Str2Float 却用 Convert 抛异常，错误处理不一致。配置中 -1 哨兵值被静默转 0
P1-6WarrorController.PlayerNeedMovegetter 内执行 FindTargetForMove_MinDistance（物理查询），属性读取代价高且有副作用。性能隐患 + 语义混乱

🟡 P2 — 工程质量 / 可维护性

较上次评估增加 1 项：死亡事件订阅缺失（原 P1-3 降级，因死亡主链路已由 FSM Dead 状态打通）。

编号位置问题
P2-1目录结构ConfigData 被拆成两处（Scripts/ConfigData 与 BattleFreamwork/ConfigData），EffectManager/ConfigManager 与 SkillData 分家。
P2-2StringConst.csMonoBehaviour 却全是 static 常量，混入登录/密码/背包/UI Panel 等非战斗业务常量。
P2-3Skill.cs:737 / CommonHelper范围索敌用 foreach 分配；OnProbability 每次 new RNGCryptoServiceProvider + Random，热路径开销大。
P2-4EffectManager.csResaveEffect/OndDestroyEffect/OnAttackAudio 等为死代码；CommonHelper.GetRootParticleParent 存在空引用分支。
P2-5命名Warror/Warrior 拼写混用、SkillData 大量 Para1..Para16 魔法字段、AttackDicNum 等错拼。
P2-6TestPlayer/TestEnemy用 Debug.LogError 输出普通调试信息（污染错误日志）；真实战斗 CreadHero/CreadNPC 被注释禁用。

P2-8CombatUnit.csOnDeadEvent / OnDead 死亡事件从未被 += 订阅（死亡主链路已由 FSM Dead 状态打通，此处仅观察者无人响应）。
