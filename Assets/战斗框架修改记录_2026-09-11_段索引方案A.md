## 1. 一句话改动总览

在 `Skill` 类里加一个 `m_SegIdx` 计数器,每次 `OnSkillCase` 回调时 `+1`,`OnDamaged` 处通过 `attacker.m_CurSkill.SegIdx` 索引 `HitEffect[segIdx - 1]` 选取该段对应特效。`OnSkillCase` 入口的"新一轮技能执行检测" + `BeginNextSegment` 帧间隔超时 + `IdleState.OnEnter` 三处作为兜底重置点。

### 3.1 `Skill.cs` — 新增字段与方法(改动 #1)

**位置**: 第 141 行 `private GameObject m_SkillCaseter = null;` 之后

**Before**:
```csharp

private GameObject m_SkillTarget = null;

public void SetSkillCaster(GameObject m, GameObject tar)
{
    m_SkillCaseter = m;

}
```

**After**:
```csharp
private GameObject m_SkillCaseter = null;
private GameObject m_SkillTarget = null;

/// <summary>
/// 当前正在播放的段索引(1-based,0=未开始)
/// 方案A:事件顺序自动计数 —— 每次 OnSkillCase 回调 BeginNextSegment() 自增
/// 由 SetSkillCaster 入口自动归零(对象池复用 / 新技能开始 / 帧间隔超阈值也会归零)
/// 下游 OnDamaged 通过 attacker.m_CurSkill.SegIdx 直接读取,索引 HitEffect[segIdx-1]
/// </summary>
private int m_SegIdx = 0;
private int m_LastSegFrame = -1;
private const int SEG_TIMEOUT_FRAMES = 60; // 约 1 秒,超阈值认为上一段是上一技能残留,自动归零
public int SegIdx { get { return m_SegIdx; } }

/// <summary>
/// 进入下一段(动画事件回调入口):超时容错后自增并返回新段号
/// 首次调用返回 1,第二次返回 2,以此类推
/// </summary>
public int BeginNextSegment()
{
    if (Time.frameCount - m_LastSegFrame > SEG_TIMEOUT_FRAMES)
    {
        // 兜底:跨技能或超 1 秒无新事件,强制归零
        m_SegIdx = 0;
    }
    m_SegIdx++;
    m_LastSegFrame = Time.frameCount;
    return m_SegIdx;
}

/// <summary>
/// 显式重置段索引(由 CombatUnitController.ResetSkillSegIdx 在 IdleState 等时机调用)
/// </summary>
public void ResetSegIdx()
{
    m_SegIdx = 0;
    m_LastSegFrame = -1;
}

public void SetSkillCaster(GameObject m, GameObject tar)
{
    m_SkillCaseter = m;
    m_SkillTarget = tar;
    ResetSegIdx(); // ★ 新段位:每次新技能施放都从段 1 开始计数
}
```

**做了什么**:
- 新增 `m_SegIdx`(当前段号)、`m_LastSegFrame`(上次事件帧号)、`SEG_TIMEOUT_FRAMES=60` 三个字段
- 新增 `SegIdx` 只读属性(供 `OnDamaged` 读)
- 新增 `BeginNextSegment()` 自增方法(带 1 秒超时容错)
- 新增 `ResetSegIdx()` 显式重置方法
- `SetSkillCaster` 末尾追加 `ResetSegIdx()` 调用

## 4. 重置点设计(防错三道关 · 修正版)

> ⚠ **2026-09-11 修正**:原版第 1 道"新技能开始"放在 `Skill.SetSkillCaster` 是错的——
> `OnSkillCase` 每次事件回调都会调 `SetSkillCaster`(每个段位 1 次),
> 在这里重置会让计数器永远停在 1。
> **修正**:移除 `SetSkillCaster` 的重置,改到 `CombatUnitController.OnSkillCase` 入口
> 做"新一轮技能执行检测"。

| # | 触发时机 | 位置 | 作用 |
|---|---|---|---|
| 1 | **新一次技能执行** | `CombatUnitController.OnSkillCase` 入口检测 `isNewExecution`(`skillId` 变化 / 帧间隔 > 30 帧) | 半路切新技能 / 长间隔重入时强重置 |
| 2 | 帧间隔 > 60 帧(约 1 秒) | `Skill.BeginNextSegment` 入口超时检测 | 任何遗漏重置的兜底 |
| 3 | 进入 `IdleState` | `CombatStates.IdleState.OnEnter` → `ResetSkillSegIdx` | 技能打断 / 完成 后的最后兜底 |

**3 道关同时存在 = 即使其中任何一道失效,其它两道仍能纠正**。

## 5. 数据流(3 段技能为例)

```
[动画 Clip 10003]                [代码]                        [效果]
3 个事件(0.2s/0.6s/1.0s)         OnSkillCase(args)
  ↓ (仅传 skillId=10003)         m_CurSkill = skill
                                 m_CurSkill.BeginNextSegment()  ← 第 1 次返回 1
                                 m_CurSkill.SkillHit(...)
                                   ↓
                                 SkillHit → HitTarget
                                   ↓
                                 ImmedDamage → OnDamaged
                                   ↓
                                 segIdx = attacker.m_CurSkill.SegIdx = 1
                                 → HitEffect[0] = 0 → 播特效 0    ← 段 1
  第 2 个事件                     m_CurSkill.BeginNextSegment()  ← 第 2 次返回 2
                                 → HitEffect[1] = 5 → 播特效 5    ← 段 2
  第 3 个事件                     m_CurSkill.BeginNextSegment()  ← 第 3 次返回 3
                                 → HitEffect[2] = 6 → 播特效 6    ← 段 3

[新技能 / 进入 Idle]            ResetSegIdx() 自动/手动
  → m_SegIdx = 0                 下次 BeginNextSegment 重新从 1 开始
```

## 10. v2 修复记录(2026-09-11 09:25)

### 10.1 用户反馈的 bug

> "我现在一个技能整个播放过程中要多次的调用 OnSkillCase 这个方法,现在每次调用这个方法的时候都会执行 Skill.SetSkillCaster,而每次调用的你都重置了攻击次数的记录,那这样完全不对吧"

### 10.2 根因分析

v1 实现把 `ResetSegIdx()` 放在 `Skill.SetSkillCaster()` 内。但 `OnSkillCase` 内部会调用 `SetSkillCaster` **3~4 次**(player / NPC 两条分支各两次):

```csharp
// CombatUnitController.cs 第 976/980/1003/1008 行
skill.SetSkillCaster(gameObject, null);          // ①
skill.SetSkillCaster(gameObject, m_Target.gameObject);  // ②
skill.SetSkillCaster(gameObject, m_Target.gameObject);  // ③
skill.SetSkillCaster(gameObject, m_Target.gameObject);  // ④
```

每次 `SetSkillCaster` 都把 `m_SegIdx` 重置为 0,然后 `BeginNextSegment` +1 = 1。3 段技能每段都看到 segIdx=1,**永远只触发段 1 的特效**。

### 10.3 修复方案(两层)

#### 修复 ①:`Skill.SetSkillCaster` 移除 `ResetSegIdx()`

**文件**:`Skill.cs` 第 180~189 行

**Before**:
```csharp
public void SetSkillCaster(GameObject m, GameObject tar)
{
    m_SkillCaseter = m;
    m_SkillTarget = tar;
    ResetSegIdx(); // ★ 新段位:每次新技能施放都从段 1 开始计数
}
```

**After**:
```csharp
public void SetSkillCaster(GameObject m, GameObject tar)
{
    m_SkillCaseter = m;
    m_SkillTarget = tar;
    // ⚠ 注意:此处不再调用 ResetSegIdx()
    // 原因:OnSkillCase 在每次动画事件回调时都会调用本方法(每个段位 1 次),
    //    如果在这里重置,3 段技能每段都会被重置成 0,BeginNextSegment 又 +1 = 1,
    //    永远只看到段 1,无法区分多段。
    // 重置职责移到 CombatUnitController.OnSkillCase 的"新一轮技能执行检测"。
}
```

#### 修复 ②:`CombatUnitController.OnSkillCase` 入口加"新一次执行"检测

**文件**:`CombatUnitController.cs` 第 74~80 行(新字段)+ 第 970~983 行(新逻辑)

**新字段**(放在 `NpcCombatUnit` 后):
```csharp
private int m_LastOnSkillCaseSkillId = int.MinValue;
private int m_LastOnSkillCaseFrame = -1;
private const int ON_SKILLCASE_NEW_EXEC_TIMEOUT_FRAMES = 30; // 约 0.5 秒,跨次执行兜底
```

**新逻辑**(放在 `OnSkillCase` 解析 `skillId` 之后、所有 `SetSkillCaster` 之前):
```csharp
bool isNewExecution =
    skillId != m_LastOnSkillCaseSkillId ||
    Time.frameCount - m_LastOnSkillCaseFrame > ON_SKILLCASE_NEW_EXEC_TIMEOUT_FRAMES;
if (isNewExecution && m_CurSkill != null)
{
    m_CurSkill.ResetSegIdx();
}
m_LastOnSkillCaseSkillId = skillId;
m_LastOnSkillCaseFrame = Time.frameCount;
```

### 10.4 修复后 4 个场景验证表

| 场景 | 触发条件 | 行为 | 段号 | 是否符合预期 |
|---|---|---|---|---|
| 3 段技能正常播放(同 skillId,帧间隔小) | `skillId==LastSkillId` 且帧差 < 30 | 事件 1/2/3 都走 `isNewExecution=false` | 1→2→3 | ✓ |
| 半路切新技能(同动画,不同 skillId) | `skillId!=LastSkillId` | 新技能首事件触发 `ResetSegIdx` | 0→1 | ✓ |
| 同技能打完回 Idle 再放 | 帧间隔 > 30 或 IdleState.OnEnter 已归零 | `isNewExecution=true` 或 `m_SegIdx=0` | 0→1 | ✓ |
| 同技能 1 秒后再放(未走 Idle) | 帧间隔 > 30 | `isNewExecution=true` | 0→1 | ✓ |
| **同技能 30 帧内连放(未走 Idle)** | 帧间隔 < 30 且 skillId 同 | `isNewExecution=false` | 续号(可能错位) | ⚠ 边界未覆盖 |
